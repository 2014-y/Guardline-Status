Guardline Status v3.1.0 旗舰版 封条与门禁守护 Windows 10 / 11 (x64)
面向软路由（OpenWrt / ImmortalWrt）与 OpenClash (Mihomo) 的桌面智能出口安全管控终端
Guardline Status 将原本分散在路由器 SSH 命令行、LuCI 网页后台与 OpenClash 控制面板中的核心能力整合至一个轻量、无边框的原生桌面窗口。应用专为跨区纯净住宅 IP 出口守护、移动多场景上游组网与内核级分流流量审计打造——无需登录繁琐后台或记忆复杂指令，即可实时掌控出口安全状态、一键防失联切换周边 Wi‑Fi 热点、安全同步代理节点白名单、查询全周期分流账单并精细化管理内网接入终端。
五源出口安全门禁 5 Probes
链路波动或重载瞬间自动关闸阻断，经 5 路独立探针一致确认为目标住宅 IP 后自动放行，杜绝真实 IP 裸连泄露。
30 秒防失联桥接 Rollback
切换上级 Wi‑Fi 前自动备份无线配置快照；若密码有误或 30 秒未获 IP 自动还原原桥接，绝不锁死路由器后台。
内核旁路分流审计 nftables + DB
基于只读 nftables 旁路计量与本机 SQLite 持久库，零丢包区分代理与直连流量，支持 6 级时间粒度与 CSV 导出。
本机硬件级凭据加密 Win DPAPI
路由器 SSH 账号密码与常用 Wi‑Fi 记忆库均采用 Windows 系统级 DPAPI 加密落盘，仅当前系统账户可解密读取。
八大核心功能模块详解
点击各模块右上角「前往」可快速跳转体验
01 状态面板 全景态势仪表盘
采用 Bento 模块化大屏布局，一屏聚合出口 IP 状态、实时上下行速率波形、联网场景识别、硬件负载与活跃会话速览。
出口与门禁总览：实时识别出口地区代码、公网住宅 IP、当前选用节点、系统运行时长及五源门禁放行状态，右上角太阳花按钮支持一键强制全量同步。
双通道平滑速率图：动态绘制上传与下载实时网速、历史峰值速率与累计字节数，点击速率卡可直接跳转至流量统计明细页。
多维监控与快切：直观展示三种联网方式（主用与热备状态）、内网网关一键复制、四维健康指标（延迟/节点/桥接/温度）、CPU/内存双段进度条，以及实时连接/在线终端/上网线路三合一表格与策略组速览。
02 无线桥接 WWAN 上游热点管理
让软路由在无网线环境（酒店、办公室、移动办公）下无线桥接上级 Wi‑Fi 联网，或在插网线时作为备用无线 WAN 热备线路。
双频扫描与隐藏接入：一键扫描周边 2.4G / 5G 热点，展示 dBm 信号格、信道及 WPA2 / WPA3 / 开放网络协议，支持按频段筛选及手动添加隐藏 SSID。
内置防失联自愈机制：发起桥接或修改密码前自动备份原配置；若 30 秒内密码错误或未获取到上级 IP，自动还原原无线状态，避免锁死后台。
常用 Wi‑Fi 记忆库：支持加密保存多个常用办公点或手机热点凭据，后续一键免密切换、在线改密或断开桥接；全程仅操作 wwan 接口，绝不触碰代理与防火墙配置。
03 代理节点 策略选路与订阅同步
深度集成 OpenClash / Mihomo 控制接口，提供直观的策略组切换、节点并发延迟测速以及受封条保护的订阅在线更新流程。
策略组与节点筛选：支持鼠标按住拖拽或滚轮滑动切换策略组，支持智能/延迟/名称排序、节点名与协议搜索、「仅显示可用节点」过滤及一键定位当前选用节点。
并发一键测速：并发探测当前组全部节点真实连通延迟并以绿/黄/橙/红四色直观标注，点击任意节点卡片可呼出右侧详情抽屉查看承载会话与单点测速。
封条级订阅更新向导：支持输入在线 Clash.Meta 订阅链接或直接粘贴 YAML 配置更新节点；自动经 root 封条认证同步中继白名单（mainland-nodes.list）并重载防泄露规则，支持更换家宽订阅时关闸探测新出口 IP 自动对齐门禁。
04 流量统计 代理 / 直连分流审计
在内核层精准剥离「代理流量、直连流量、总流量」并实现跨重启 24×7 持久化归档，告别传统面板重启后流量归零的痛点。
六级粒度与精确时段：支持「5 分钟 / 按时 / 按天 / 按月 / 按季 / 按年」六种聚合粒度，提供今日、近 24 小时、近 7/30 天、本月/季/年、近 5 年快捷预设及精确到分钟的自选起止时间查询。
交互式双模式图表：配备分流构成环形图与趋势柱状图，支持「堆叠总览 / 并列对比」一键切换，鼠标悬停可查看任意时间桶的上下行及占比明细。
分时段账单与 CSV 导出：下方明细表支持过滤无流量空周期与正倒序排列，支持一键将当前查询区间导出为桌面 CSV 表格文件或手动清零历史记录。
05 实时连接 活跃会话与规则追踪
秒级透视局域网内全部终端当前发起的活跃网络连接，清晰验证每一个域名或目标 IP 实际命中的分流规则与最终出口节点。
全链路字段展示：实时列出连接来源设备（自动匹配自定义备注名）、访问目标域名/端口、命中规则（Rule & Payload）、完整决策链路、实时上下行速率及持续时长。
多维组合检索：支持按「来源终端设备」与「出口代理节点」下拉定向过滤，并可通过关键字即时搜索目标域名、远端 IP 或规则名。
快照定格与抽屉透视：点击「暂停刷新」可冻结当前会话列表逐条排查分流异常；点击任意行可在右侧抽屉查看源端口、嗅探信息与协议入口详情。
06 终端设备 局域网客户端管理
统一纳管通过有线网口及 2.4G / 5G 无线热点接入软路由的全部手机、电脑与智能设备，实时掌握在线状态与单机带宽占用。
多源融合状态识别：结合 DHCP 租约、ARP 邻居表、无线射频客户端与代理连接表，精准呈现「在线 / 空闲 / 离线 / 封禁」状态并自动标注当前本机设备。
无线信号与单机网速：实时监控无线接入频段（2.4G / 5G Wi‑Fi）、dBm 信号强度格、单设备实时下载/上传速率及累计收发流量。
一键复制与自定义备注：点击设备 IP 或 MAC 地址即可一键复制；点击编辑按钮可为设备绑定易读的中文备注名（如「主力工作站」），全系统联动展示。
07 系统信息 拓扑与底层硬件遥测
提供旗舰级四段动态网络拓扑流向图与硬件遥测看板，深度呈现路由器底层内核、多线网关、双频无线射频与安全门禁参数。
全链路动态脉冲拓扑：可视化串联「局域网终端 → 软路由网关 → 代理引擎与门禁 → 国际住宅出口」四个核心环节，实时显示链路延迟与流向状态。
硬件、多线与射频矩阵：环形仪表实时监测 CPU、内存与芯片温度；详列主板型号、固件内核、有线 WAN / 无线 WWAN / 4G·5G 接口矩阵（含 IPv6 防泄露状态）及本机双频 AP 信道、频宽与发射功率。
引擎与封条门禁详情：集中展示预期住宅出口 IP、5 颗探针一致性指示灯、Guardline 封条保护状态及策略组/节点/活跃会话核心计数。
08 系统配置 多路由切换与外观定制
支持多台软路由自动探测与多账号加密记忆切换，并提供主题色、深浅模式、无级字号缩放与 Windows 系统托盘后台常驻配置。
网关自动发现与多路由记忆：自动探测局域网默认网关与 OpenWrt 设备，兼容 root 或自定义管理账号及自定义 SSH 端口，支持多台软路由一键秒切。
个性化视觉与无障碍缩放：支持珊瑚橙、暖珀金、海洋蓝、翡翠绿多款主题色及暗黑/浅色双模式，支持 A- / A+（90%～124%）界面缩放与窗口置顶。
系统托盘常驻与秒开体验：可配置点击右上角 × 时最小化驻留 Windows 系统托盘，后台低耗保活、单击图标 0 秒唤出，并支持一键打开路由器网页后台。
底层安全守护与高可用工程机制
核心安全基座
出口 IP 门禁阻断保护（Kill-Switch）自动值守
当上游 Wi‑Fi 切换、宽带重拨或代理节点异常时，路由器门禁在毫秒级关闭转发通道，待后台连续通过 5 个公网探针源确认出口已恢复为预期住宅 IP 后自动开闸放行。
Guardline 封条防篡改与 IPv6 防泄露无损隔离
大陆中继白名单与防泄露防火墙规则受 root 封条保护；同时自动识别并守护上游 IPv6 关闭状态，防止双栈环境下通过 IPv6 旁路泄露本地网络指纹。
无线桥接 30 秒快照自愈（Anti-Lockout）防锁死回滚
切换或修改上级 Wi‑Fi 前自动创建原无线配置快照；若 30 秒内密码有误或未获取到上级 IP，自动回滚恢复原桥接与本机 AP，确保管理连接永不失联。
内核旁路零损计量与双频遥测（2s + 10s）超低开销
采用只读 nftables 旁路分流计量与单条加密 SSH 长连接快慢分层采集，零丢包且不触碰封条规则，7×24 小时常驻运行对软路由 CPU 几乎零感知。
Windows DPAPI 凭据加密与单实例自愈本地安全
所有账号密码经 Windows Crypt32 DPAPI 硬件级绑定加密，拒绝明文落盘；桌面端内置命名互斥锁与进程自愈机制，重复启动自动唤醒已有窗口。
